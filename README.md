## Structure du projet

```
exercices_poo/
├── exo01_compteur_page/
├── exo02_article/
├── exo03_carnet_adresses/
├── exo04_cercle/
├── exo05_journal_taches/
├── exo06_convertisseur/
├── exo07_ressource/
├── exo08_vecteur/
├── exo09_dataclass/
├── exo10_decorateurs/
├── run_all.py
└── README.md
```

## Exécution

Ouvrir le fichier `main.py` d'un exercice, puis `Run As > Python Run`. Pour lancer tous les exercices à la suite, exécuter `run_all.py`.
